# E-Commerce Project (CRUD)

This is a simple e-commerce website made using HTML, CSS and JavaScript. In this project I can add, edit, view and delete products and also manage a shopping cart. The data is saved in the browser using localStorage so it stays after refreshing the page.

## Features

- Add Product
- Edit Product
- View Product
- Show Single Product
- Delete Product
- Add to Cart
- Increase and Decrease Product Quantity
- Total price of the cart
- Remove From Cart
- Show Cart
- Searching products by name
- Filtering products by category
- Sorting products by price and name

## Technologies Used

- HTML
- CSS
- JavaScript

## Files

- index.html - main page
- style.css - styling
- script.js - all the JavaScript code

## How to Run

1. Download the project folder.
2. Open index.html in any browser.

## How it Works

- Products are stored in an array and saved in localStorage.
- Add and Edit use the same form. When we click Edit the old details come in the form.
- Add to Cart puts the product in the cart. If it is already there then the quantity increases by 1.
- The cart total is found by adding price x quantity of every item.
- Search, filter and sort work together on the product list.
